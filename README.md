# P16: сравнение форм триггера

Учебный проект по сравнению пяти форм backdoor-триггера на изображениях:

- локальный патч;
- полоса;
- изменение яркости;
- изменение положения изображения;
- изменение оттенка цвета.

Главный вопрос: какой триггер модель легче выучивает при одинаковой доле отравления и сопоставимой заметности для человека?

## Идея эксперимента

Для части обучающих изображений нецелевых классов применяется триггер, а метка заменяется на выбранный целевой класс. После обучения модель проверяется в двух режимах:

1. чистые тестовые изображения - измеряем обычную точность;
2. те же изображения других классов с триггером - измеряем долю перехода в целевой класс (ASR).

Основной ASR считается только по изображениям нецелевых классов. Дополнительно считается условный ASR только по тем изображениям, которые модель правильно распознала до добавления триггера. Так собственные ошибки модели не смешиваются с действием закладки.

## Быстрый старт

Создание окружения и установка:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[train,dev]"
```

Проверка кода:

```powershell
python -m unittest discover -s tests -v
```

Создание демонстрационной сетки триггеров без загрузки датасета:

```powershell
python scripts/preview_triggers.py
```

Результат сохраняется в `artifacts/trigger_preview.png`.

## Первый основной эксперимент

- данные: CIFAR-10;
- модель: компактная CNN;
- режим: dirty-label targeted backdoor;
- целевой класс: `0`;
- доли отравления: `1%`, `3%`, `5%`;
- повторения: три seed;
- сравнение: одинаковая доля отравления и отдельно сопоставимая визуальная заметность.

Подробный протокол находится в [docs/experiment-plan.md](docs/experiment-plan.md).

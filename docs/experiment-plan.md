# Экспериментальный протокол

## Что сравниваем

Пять форм триггера проверяются при одинаковой модели, одинаковом целевом классе, одинаковых индексах отравленных объектов и одинаковом бюджете обучения.

Основных режима два:

1. одинаковая доля отравления;
2. приблизительно одинаковая заметность для человека.

Глобальную яркость нельзя честно приравнять к маленькому патчу только по числу измененных пикселей. Для второго режима используются сетка изображений, среднее изменение пикселя, PSNR, SSIM, цветовое расстояние и небольшая слепая человеческая оценка.

## Тест на картинках других классов

Пусть целевой класс - `самолет`. На тесте берем котов, собак, машины и остальные нецелевые классы:

1. сохраняем ответ модели на чистом изображении;
2. добавляем триггер к тому же изображению;
3. проверяем, стал ли ответ равен `самолету`.

Результаты делятся на три группы:

- корректно распознанные нецелевые изображения - основная оценка эффекта триггера;
- уже ошибочно распознанные изображения - отдельная диагностическая группа;
- изображения целевого класса - не включаются в ASR, потому что целевой ответ для них и так правилен.

## Этапы

1. Обучить чистую базовую модель для каждого seed.
2. Визуально проверить пять триггеров на одинаковых изображениях.
3. Провести пилот трех уровней силы при доле отравления 3%.
4. Выбрать примерно сопоставимые по заметности уровни силы.
5. Запустить матрицу: 5 триггеров x 3 доли отравления x 3 seed.
6. Рассчитать обычную точность, падение точности, ASR, условный ASR, ASR по исходным классам и запас целевого логита.
7. Построить кривые ASR от доли отравления и график ASR против заметности.
8. Проверить перенос патча между разными позициями.

## Главные метрики

- `A_base`: точность чистой модели;
- `A_poison`: точность модели с закладкой на чистом тесте;
- `Delta A = A_base - A_poison`;
- `ASR`: доля нецелевых изображений, ставших целевым классом после триггера;
- `conditional ASR`: то же, но только среди правильно распознанных до триггера изображений;
- `S(c)`: ASR отдельно для каждого исходного класса;
- `m_trigger`: запас логита целевого класса;
- показатели визуальной заметности.

Триггер считается особенно опасным, если ASR высок, а падение обычной точности и заметность малы.
